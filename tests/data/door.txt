# The door where clippy cannot hold it (tests/source.rs,
# the_door_holds_what_clippy_cannot). Columns, tab-separated:
#   kind  file  scope  count  reason
# allow:   an allow or expect that silences the door's lint
#          (scripts/door/clippy.toml), by the scope it governs, as
#          tests/lex names it: <file> for a module's own, Type::<item> for
#          a type's body, a fn of a nested module by its own name.
# literal: a "/proc" or "/sys" path written outside the door's modules.
# thread:  thread:: paths in a file's code, the door's modules included,
#          until S1's pin:: wrappers (decision 11).
# cfgout:  a cfg whose predicate does not hold in the door's build (the
#          library under checked on Linux x86_64, glibc), outside the
#          door's modules: code the door's lint never compiles, held by
#          text (no path the config bars may be written in it).
# Every count is exact: one that grows, moves or falls fails until this
# file says so, with the reason.
#
