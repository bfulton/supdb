# The wall between the forms and the encryption modules (tests/source.rs).
# One line per (file, scope, token, region). Tab-separated columns:
#   file    path under the crate root
#   scope   the enclosing fn as Type::fn or fn, outer>inner for a nested fn;
#           Type::<item> for a type's body or an impl's header; "const NAME",
#           "struct NAME", "mod NAME" for a top-level item
#   token   a token class of tests/source.rs (cipher_tokens, form_tokens);
#           vault::NAME for a vault item that is not a door verb (DOOR)
#   region  code (strings included, comments not) | test (an item under a cfg
#           that implies test, or a #[test] fn)
#   count   occurrences
#   stage   where the line is expected to reach zero: G1 G3 R4 S1 S5 S6,
#           "S4 (conditional; else stays)", or "stays"
#   reason
# The gate compares the totals by (file, token, region), both ways: a total
# above the file's fails as growth, one below it fails until the file is
# lowered in the same change. The scopes say where; a coupling moved between
# scopes changes no total. SUPDB_WALL_PRINT=1 prints the measured table.
