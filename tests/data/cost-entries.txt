# The plain-cost job's entry points (scripts/cost.sh; tests/source.rs holds this
# file to the tree). One line a pub fn of impl Reader, impl Db and impl Blob, a
# fn of an impl of a trait for one of them (Type::Trait::fn) or for a generic
# parameter of the impl's own, which may be any of them (*::Trait::fn), and a
# macro invoked where an item of such an impl stands (Type::name!); an impl
# through an alias of a type is that type's:
#   Type::fn<TAB>probe[,probe]      the probes of scripts/cost.sh that count it
#   Type::fn<TAB>-<TAB>reason        why no probe does
# A probe named counts the function where the probe's toggle runs it; a reason
# says the function is not on an operation's path, or names the gap.
