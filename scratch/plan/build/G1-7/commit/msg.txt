The read path's whole borrows are sealed to their readers: lend_at takes the format reader's token, the mapping's whole slice the ordered index's or the stride form's, and the records answer by kind

What is held. Bytes::lend_at, the borrow of a range held whole, takes a
token made in blob alone (blob::lend::Token, its constructor
pub(in crate::blob)), so no code outside the format's reader can call it
and no source outside the crate can override it. MmapBytes::as_slice is
deleted; its crate-private successor MmapBytes::lent takes a token of each
reader that borrows a mapping whole, the ordered index's and the stride
form's, through a trait of a private module of the seam. Paging is
crate-private and its base takes bytes::Base, which only the seam makes.
Blob::record_regions and record_pieces are one crate-private
Blob::records answering Whole or Pieces, and every caller names both
arms. The warm's touch of a mapped file's pages is MmapBytes::touch, the
seam's own, which touches nothing of a paged mapping; the pagemap test
reads the mapping's address through a test-only accessor. The sentences
owed at Own and MmapBytes::map() say that a third kind answering None
there would read as authenticated.

How it was shown red. Compile-fail doctests in the crate docs, each beside
a twin that compiles (as_slice, lend_at without and with a token, an
outside override, naming Paging, record_regions, record_pieces): six
compiled before the change and fail after. scripts/seal-red.sh, in the
lint group, compiles each sealed call at home and refuses it abroad at its
own line; scripts/seal-red-red.sh is its own red input, failing it by exit
status at each check. tests/source.rs reads the tree for the seal: every
token made only where it is spent, every lent call in a listed reader,
lend_at named nowhere outside blob, and each name read by every spelling
that reaches it -- a qualified path, a renamed or glob import, a call by
type or through a function value, and inside a macro's tokens the words
lent and lend in any position but four listed test assertions. Its red
cases are the spellings review wrote that compiled and passed earlier
versions of the check, the macro-forwarded hand-out and spend among them.

What it cannot see. A seal is as wide as its token's constructor: a
derive, a Default, a function of the reader's module handing a token out,
or unsafe code all compile, and the source test is what refuses them, as
text. It cannot read a name a macro builds from pieces or code included
from outside a file. The compile-fail doctests check that a snippet fails,
not why. A call whose argument diverges compiles and never reaches the
method.
